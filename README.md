# 📖 英文 PDF 朗讀機

上傳英文 PDF，網頁就會一句一句唸出來，可以調整速度，也可以下載成音檔。

- **完全免費、不用伺服器**：語音模型（[Kokoro](https://github.com/hexgrad/kokoro)）直接在瀏覽器裡執行，PDF 不會上傳到任何地方
- **聲音自然**：AI 語音，可選美式 / 英式、男聲 / 女聲
- **速度 0.5x～1.5x**：播放時可以隨時調整，聲音不會變尖
- **同步標示**：正在唸的句子會用黃色標起來，點任何一句就從那裡開始
- **下載音檔**：依照目前的速度產生 WAV 檔，可以放到手機裡離線聽
- 中文字會自動略過不唸

> 第一次開啟要下載約 90MB 的語音模型，之後瀏覽器會記住，不用再下載。

## 本機執行

```bash
python -m http.server 8000
```

然後用瀏覽器開 http://localhost:8000

## 部署到網路上（讓手機可以用）

手機要用的話需要 HTTPS 網址，最簡單是用 **GitHub Pages**（免費）：

1. 把這個資料夾推到 GitHub
2. Repo → Settings → Pages → Source 選 `main` 分支、根目錄 `/`
3. 等一兩分鐘，就會得到 `https://你的帳號.github.io/repo名稱/` 的網址

也可以用 Netlify / Cloudflare Pages，直接把資料夾拖進去即可。

## 限制

- 掃描的 PDF（整頁都是圖片）讀不到文字，目前不支援
- 手機上產生語音比電腦慢，建議先按 ▶ 開始聽，後面的句子會在背景準備
- 下載檔是 WAV 格式，10 分鐘大約 30MB

## 檔案說明

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 頁面 |
| `style.css` | 樣式（大字、大按鈕，方便長輩使用） |
| `app.js` | PDF 解析、分句、播放、下載 |
| `tts-worker.js` | 在背景執行 Kokoro 語音模型 |
